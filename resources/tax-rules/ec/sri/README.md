# Rulesets tributarios del SRI

Este directorio contiene únicamente manifiestos, secciones revisadas y bundles
versionados. Los originales descargados y borradores viven fuera de Git en
`.cache/tax-rules/`.

Los manifiestos iniciales son borradores de descubrimiento: no contienen hash,
no activan reglas y no deben utilizarse durante un análisis.
